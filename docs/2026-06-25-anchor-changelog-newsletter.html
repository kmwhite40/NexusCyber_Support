Headline Capabilities Shipped

1. Platform User Administration MAJOR NEW

A new /team page (gated by admin.users.manage) to administer platform (nexus) staff: roles, status, local password, and organization scope.

  • Scope a delegated admin to specific orgs or all orgs — “all orgs” is a new grant (an org-NULL nexus role assignment + an app.all_orgs RLS flag) that gives cross-org visibility without full platform-superuser.
  • Guardrails — only a SuperAdmin may grant all-orgs or assign the SuperAdmin role; delegated admins act only within their own scope. Every change is audit-logged; /me now exposes the caller’s scope.
  • Break-glass — three dedicated local SuperAdmin accounts for sign-in where SSO/dev-login is unavailable.

2. ITSM Depth — Change Calendar + CMDB NEW

  • Change calendar — a month-grid view of scheduled & implementing changes by window, risk-colored, with click-through to the change.
  • CMDB depth — configuration items gained extensible attributes (JSONB), owner/support-group, and a real ci_relationships graph (depends_on / runs_on / hosts / connects_to / member_of / uses) with RLS isolation and a CI detail editor.
  • Problem management was reviewed and confirmed already complete (RCA, known-error, workaround, incident clustering) — no rebuild needed.

3. Flow Designer + Report Builder NEW

  • Flow / workflow designer — the automation builder now composes multi-condition (ALL/ANY) groups and an ordered list of actions with reordering and a live flow read-back, persisted as the existing rule JSON.
  • Self-service report builder — a new Analytics tab to pick a dimension + measure + filters over ticket data (safelisted to prevent injection), rendered as a bar table with CSV export.

4. Virtual Agent — “Ask Anchor” NEW

A retrieval-grounded self-service assistant on the customer portal: a natural-language question returns the best knowledge-base answer, related articles, and matching catalog actions, and deflects to a pre-filled ticket when nothing fits.

  • In-boundary by design — KB full-text + catalog only, no external LLM (the gov enclave disables AI egress). A synthesis step can layer on if/when an AI capability is enabled.

5. Knowledge Base — Library, Audit & Deflection NEW FIX

  • Self-service library — added global Help Desk articles: account/MFA/Intune/email/onboarding how-tos plus ~15 typical-problem troubleshooting guides (slow PC, Wi-Fi, printer, Outlook, Teams, OneDrive, display, audio, disk, shared folders, browser, crashes, access denied, Bluetooth).
  • Audit fixes — removed 3 cross-space duplicate articles (now 67 pages, 0 duplicates); enriched Security articles with real endpoints + support portal / mailbox / after-hours hotline; tag hygiene (Azure Government govcloud→azure-gov; M365 govcloud→gcc-high; AWS GovCloud keeps govcloud).
  • New content types — an FAQ space, a Known Issues log, and additional onboarding (employee & manager checklists).
  • “Did this resolve your issue?” — each article now prompts the reader: Yes records a deflection and thanks them; No opens a ticket pre-populated with the article reference. Backed by kb_deflections analytics.
  • Direct-to-article routing — /kb?page=<id> deep-linking; portal search and Ask Anchor now open the exact article instead of the generic KB page.

6. Support Experience & Service Catalog NEW

  • Welcome dialog — a per-login modal (admins and all users) with support hours, the SLA priority matrix, and the after-hours hotline; resets on logout, doesn’t nag on refresh.
  • Site-wide banner — a red/white rolling banner on every page that rotates the on-call hotline notice and a CUI / FedRAMP data-handling warning (do not upload sensitive logs/credentials as ticket attachments).
  • Catalog — new User Device Intune Enrollment item (Company Portal + Outlook Classic for GovCloud); portal search results deep-link straight to a catalog item’s request form. Landing page logo restyled (stacked, centered).
  • Hotline number standardized to (800) 265-6446 across the app and help-desk documents.
