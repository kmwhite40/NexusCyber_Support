Headline Capabilities Shipped

1. CMMC L2 SSP — FedRAMP Appendix A Generator (v2) MAJOR NEW

A new, fully additive CMMC Level 2 SSP generator that documents all 110 NIST SP 800-171 Rev 2 requirements in the FedRAMP System Security Plan Appendix A control style. The legacy 18-section generator is untouched; an admin picks the template version per export at /documentation.

  • Faithful Appendix A layout — every requirement renders a Control Summary Information table (responsible role, organization-defined parameters, implementation-status & control-origination checkboxes) plus a “What is the solution and how is it implemented?” table with one narrative per NIST SP 800-171A assessment objective (14 families · 110 requirements · 302 objective parts).
  • Three formats at parity — Markdown, self-contained print-ready HTML, and a true Word .docx (navy headings, boxed tables, CUI banner + footer, page numbers).
  • Per-export version toggle — “Legacy (data-driven 18-section)” vs “v2 (FedRAMP Appendix A, 110 reqs)” selectable in the SSP Generator UI.
  • Faithful by construction — the dataset is a structured extraction of the source DOCX template, guarded by tests asserting the 110 / 14 / 302 counts and per-family breakdown.

2. Tenant-Data + Evidence Auto-Population MAJOR

v2 doesn't just template — it fills itself in from the platform. A pure enrichment layer joins the Appendix A shell against real tenant data and augments (never replaces) the assessor-facing draft for each requirement where data exists.

  • Four tenant sources — per-objective assessment records (status, notes, evidence), bound evidence artifacts (title / source / type / freshness), open POA&M items, and the tenant's overall CMMC score distributed proportionally per family as a status fallback.
  • Auto-checked status & origination — the Implementation-Status box is set from the rolled-up objective status; Control Origination is auto-marked “Shared” only when the backing evidence is CSP-sourced. Every auto-derived value is flagged (auto-derived from platform — confirm).
  • Confidence labeling — each requirement is tagged evidence-backed, assessed, or score-estimate; a score-only requirement renders as a clearly-marked “Score-Derived Estimate” with a caveat so an estimate never reads as an evidence-backed fact.
  • Honest empty-state — with no score and no records, requirements stay a tailor-ready draft and the operator is told to run a scan / collect evidence / walk the objectives matrix first.
  • Code-split for weight — the ~330 KB Appendix A dataset and generators load on demand, trimming the Documentation bundle by ~37% for every other visitor. PERF

3. Platform-Wide UI Realignment — KpiStrip + SectionLabel Kit NEW

A shared presentation kit (KpiStrip + SectionLabel) was extracted and applied across the platform so summary stats and section rhythm read identically everywhere — a consistent command-center layout in place of ~25 bespoke stat grids.

  • Surfaces realigned — SecureScore, ComplianceMonitoring, ContinuousMonitoring, ConfigurationManager, AuditTrail, EvidenceCollection, WorkflowManagement, RiskDashboard, DLP / InsiderRisk / CCOInsights, Purview Compliance Manager, DatabaseHealth, Organizations, SecurityAudit, Microsoft365DSC, UserManagement, M365 Admin Center, AzurePolicies, DefenderCoverage, CMMC Crosswalk, AccessReviews, SensitivityLabels, Platform/System Admin, CISODashboard, GovernanceDashboard, AuditorPortal, IdentityGovernance, and the ATO Workspace summary.
  • Polish + cleanup — hover-scale refinement on KpiStrip and removal of dead cache writes uncovered during the sweep.

4. Continuous-Monitoring Maturation NEW FIX

The ConMon / Compliance-Monitoring surface moved from manual refresh to self-accruing trends and an honest multi-cloud posture.

  • Auto-captured monthly snapshots — trend history accrues on its own so charts populate without an operator remembering to sync.
  • “Sync now” in place — refresh metrics without a full reload; the sync now correctly updates the KPI tiles (previously left showing stale numbers).
  • Honest cross-cloud posture — a Secure Score tile plus a truthful AWS / cross-cloud posture panel wired to the real compliance assessment (empty AWS card is gated rather than faked).
  • Command-center realign — Compliance Monitoring reorganized into a refined command-center layout.

5. CONMONaaS Managed-Service Documentation Suite NEW

A full Continuous-Monitoring-as-a-Service documentation set landed for the managed-service offering — portfolio one-pager, offering & SOP, standards, the employee mini-runbook, customer communications playbook, the LTE Helpdesk operations + customer guide, and the after-hours on-call Rules of Engagement, all generated from versioned build scripts.

Customer-Facing Outcomes

Federal customers + MSPs can now:
  1. Generate a CMMC L2 SSP in the FedRAMP Appendix A style covering all 110 NIST 800-171 R2 requirements with a per-assessment-objective narrative — in Word, HTML, or Markdown — without disturbing the legacy generator.
  2. Have that SSP auto-populate from their own tenant — implementation status, control statements, and evidence pulled from objective assessments, bound evidence, POA&Ms, and the live CMMC score, each tagged by confidence and flagged for human confirmation.
  3. Read every dashboard the same way — a consistent KpiStrip command-center layout across the platform.
  4. Watch ConMon trends accrue on their own — monthly snapshots captured automatically, with an in-place “Sync now” and an honest cross-cloud posture.
  5. Stand up Continuous Monitoring as a managed service with a complete CONMONaaS documentation suite (SOPs, runbooks, customer guide, on-call RoE).
